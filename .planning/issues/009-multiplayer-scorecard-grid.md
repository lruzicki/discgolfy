## What to build
Create the `SummaryView` component to display a multi-player scorecard grid. The grid should be chunked into 9-hole segments and use the Aether Disc design system.

## Acceptance criteria
- [x] Grid displays all players in the match as rows.
- [x] Holes are displayed as columns, chunked by 9.
- [x] Sticky first column for player names.
- [x] Color-coded scores (+/- PAR).
- [x] Read-only view for performance review.
