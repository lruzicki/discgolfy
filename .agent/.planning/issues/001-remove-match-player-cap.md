## What to build

Allow a Match to include any number of selected Players instead of stopping the Squad at four. The Player selection screen should let the current Player add every visible friend or Guest, then start the Match with all selected Players inserted into `match_players`.

## Acceptance criteria

- [ ] Selecting a fifth Player succeeds without a "Squad Full" alert.
- [ ] The selected Player count reflects the real selected count without showing a fixed `/4` capacity.
- [ ] Starting a Match inserts every selected Player into `match_players`.
- [ ] Covered by a behavior test through the Player selection screen.

## Blocked by

None - can start immediately
